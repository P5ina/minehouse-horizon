# Chat Heads for Horizon

A native [Horizon](https://github.com/horizon-rust/horizon) mod (Minecraft 26.3): a port of
[Chat Heads](https://github.com/dzwdz/chat_heads) (MIT). The sender's head in front of each chat line: the
signed sender of a player message, else the first player-list name found in the line (servers that format
chat as system messages, join messages). Drawn as a `minecraft:object` player sprite, with the skin the
player list has.
