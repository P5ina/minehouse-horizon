# Controlling for Horizon

A native [Horizon](https://github.com/horizon-rust/horizon) mod (Minecraft 26.3): the part of
[Controlling](https://github.com/jaredlll08/Controlling) (MIT) Horizon lacks. Horizon's Key Binds screen
already has a search box (by name) and marks conflicting keys; with this mod the search also finds a binding
by the key it's on (`G`, `Left Button`) and by its category.

The native mods' keys (World Map, Zoom, Plasmo Voice, the wardrobe…) are listed at the top of Key Binds too,
one heading per mod, with the game's yellow brackets when a key is also taken by the game or another mod; a
click rebinds, Escape unbinds. Without this they are only on each mod's page in Options > Mods.
